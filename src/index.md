### First Thought - Software

You may never know how a given software stack works, especially if it was designed to be sold. There are certain fundamental things that computers *must* be able to do, however, so an implementation of some process can be portable and maintainable if it only relies on those things. Computing is not fundamentally complicated; we build complicated things out of simple parts, it is in our nature.

The point of [uxn](https://wiki.xxiivv.com/site/uxn.html) is to be a "portability layer," according to Devine. It is merely a *definition* of a virtual machine that has many implementations, purportedly promoting portability (perhaps preventing popularity, but it makes for a very interesting read). 

### Ridiculous Standards

I was reading about markdown and trying to understand how to parse it, because I want my website to be editable in a human-readable format with a text editor. I was doing a cursory Googling when I came across Redditors debating over the feasibility of this endeavour. An enthusiastic, probably young programmer wanted to parse markdown too---*great, we're in this together!* To my dismay, however, the cacophonous response of the hivemind was, *you're in too deep. Use someone else's solution and get on with your life. Your solution will never conform to the spec, there are edge cases!* I am dissatisfied with this answer. Fear of trying will get us killed.

So I will build a garbage parser, and I will convert these files into html, and I will probably screw it up pretty badly because I don't know what I'm doing, but I am tired of feeling like there is an *industry standard* way to solve every problem. I respect the explicit meaning of the phrase, and I think we build more reliable tooling when we all play by some rules we share, but it's clear to me that *industry standards* are the water presently inside a bucket placed under a waterfall. 

### Hardware

I work on an ASUS laptop running Windows 10. This is probably the pinnacle of a bloated, incomprehensible software environment, and it drives me crazy because I don't understand how it works. I would like a sustainable solution to computing: repurposed hardware running open-source software, low-power peripherals, physically portable, as minimal as possible.
